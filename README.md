# CHZZK Catch-up

치지직 라이브의 지연을 줄이고 Firefox에서 클립 편집기를 사용할 수 있게 하는 확장입니다.

## 주요 기능

- **연결 방식:** 자동(LL-HLS 우선), HLS, LL-HLS 중 선택합니다.
- **입장 시 따라잡기:** 재생이 준비되면 설정한 버퍼만 남기도록 한 번 앞으로 이동합니다.
- **즉시 따라잡기:** 버튼을 눌러 받아 둔 영상의 끝 가까이 이동합니다.
- **자동 배속:** 버퍼가 쌓이면 설정한 배속으로 따라잡고 실행 중인 배속을 표시합니다.
- **끊김 대응:** 반복 버퍼링이 감지되면 현재 방송에서 남길 버퍼를 자동으로 늘립니다.
- **재생 상태:** 최근 5초 평균 지연·버퍼·연결 방식을 표시하고 일시정지 중에는 지연·버퍼 표시를 멈춥니다.
- **클립 편집기:** Firefox에서 치지직 클립 편집기를 열 수 있도록 호환 처리를 적용합니다.

## 설치

Firefox 128 이상이 필요합니다.

- **임시 설치:** `about:debugging#/runtime/this-firefox` → **임시 부가 기능 로드**에서 `manifest.json`을 선택합니다.
- **영구 설치:** Mozilla 서명을 받은 XPI를 `about:addons` → 톱니바퀴 → **파일에서 부가 기능 설치**로 설치합니다.

임시 설치는 Firefox를 종료하면 해제되며, `dist`의 ZIP은 서명 제출용 패키지입니다.
설치·업데이트 후 치지직 사이트 접근을 허용하고 열려 있던 방송 탭을 새로고침하세요.

## 사용

- 팝업의 **따라잡기**에서 연결 방식·남길 버퍼·입장 시 동작·자동 배속·반복 끊김 대응을 설정합니다.
- 값을 바꾼 뒤 해당 **저장** 버튼을 누르며, 연결 방식은 선택 즉시 저장됩니다.
- 클립은 **클립 편집기 → 치지직 접근 허용** 후 방송을 새로고침하고 방송의 가위 버튼으로 엽니다.
- 편집기에서 소리가 없으면 음소거를 해제하고 볼륨을 올린 뒤 다시 재생합니다.

설정은 모든 방송 탭에 공통 적용되며, 지연·버퍼 조회와 즉시 따라잡기는 라이브에서 사용합니다.
클립 생성에는 치지직의 로그인·채널별 허용·생성 제한이 적용되며, 생성 완료까지는 아직 확인하지 않았습니다.
확장을 반복 재로드한 뒤 팝업이 보이지 않으면 Firefox를 완전히 종료하고 다시 실행하세요.
