# CHZZK Catch-up

치지직 라이브의 재생 지연을 줄이고 지연·버퍼 상태를 보여 주는 Firefox 128 이상용 확장입니다.

## 핵심 기능

- **연결 방식 선택:** 자동(LL-HLS 우선), HLS, LL-HLS 중 선택합니다.
- **입장 시 따라잡기:** 방송 재생이 준비되면 설정한 버퍼만 남기도록 한 번 앞으로 이동합니다.
- **즉시 따라잡기:** 버튼을 눌러 받아 둔 영상의 끝 가까이 이동합니다.
- **자동 배속:** HLS·LL-HLS에서 같은 설정으로 따라잡습니다. 실행 중에는 `>> 1.5×`처럼 표시됩니다.
- **반복 끊김 대응:** 버퍼링이 반복되면 현재 방송에서 남길 버퍼를 단계적으로 늘립니다.
- **재생 상태 표시:** 실시간 글자 옆에 지연·버퍼·연결 방식이 기본 버튼과 함께 나타납니다. 지연은 최근 5초 평균입니다.

## 설치

- **서명된 XPI:** Firefox의 `about:addons` → 톱니바퀴 → **파일에서 부가 기능 설치**에서 선택합니다.
- **소스로 임시 설치:** `about:debugging#/runtime/this-firefox` → **임시 부가 기능 로드**에서 `manifest.json`을 선택합니다. Firefox를 종료하면 해제됩니다.

설치·업데이트 후 이미 열려 있던 치지직 방송 탭을 새로고침하세요. `dist`의 ZIP은 Mozilla 서명을 받기 위한 패키지이며, 영구 설치하려면 서명된 XPI가 필요합니다.

## 사용법

1. 기본 설정에서는 방송 입장 시 LL-HLS를 우선 선택하고, 재생 준비 후 한 번 따라잡습니다. 팝업의 **자동 / HLS / LL-HLS** 버튼을 누르면 연결 방식이 저장·적용됩니다. 제공되지 않는 방식은 현재 연결을 유지합니다.
2. 어느 탭에서든 확장 아이콘을 눌러 **남길 버퍼**를 0.2~3초로 설정하고 **저장**합니다. 기본값은 0.6초이며, 작을수록 더 당기지만 끊기기 쉽습니다. **입장 시 한 번 따라잡기**도 여기서 켜거나 끌 수 있습니다.
3. 시청 중 위치를 당기려면 **즉시 따라잡기**를 누릅니다. 입장 시 이동과 이 버튼은 현재 위치부터 끊김 없이 받아 둔 영상 안에서만 이동합니다. 일시정지를 해제하거나 뒤로 이동하지 않습니다.
4. **자동 배속 따라잡기**는 시작 버퍼와 배속을 정한 뒤 **배속 설정 저장**을 누릅니다. 기본값은 버퍼 3초 이상에서 1.5배속입니다. 시작 버퍼는 남길 버퍼보다 0.5초 이상 커야 합니다.
5. **반복 끊김 대응**을 펼치면 사용 여부·감지 횟수·증가량·상한을 설정할 수 있습니다. 기본값은 최근 60초 내 0.25초 이상 버퍼링 2회마다 0.2초 증가, 상한 3초입니다. 일시정지·탐색·광고·연결 전환은 제외합니다.
6. 자동 증가한 여유는 팝업의 **현재 남길 버퍼**에서 확인합니다. 배속 시작 기준도 필요에 따라 함께 높아집니다. **자동 증가한 여유 초기화**로 되돌리거나, 다른 방송에 입장하면 기본 여유부터 시작합니다.

설정은 모든 치지직 방송 탭에 공통으로 적용됩니다. 지연·버퍼 조회와 즉시 따라잡기는 현재 탭이 치지직 라이브일 때 사용할 수 있습니다.

자동 배속은 **현재 적용 중인 여유와 0.6초 중 큰 값 이하를 감지하면 종료**합니다. 입장 시·즉시 따라잡기도 자동 증가분을 포함한 여유를 사용합니다. 끊김 대응은 따라잡기의 버퍼 소모를 줄이는 기능이며, 데이터를 즉시 더 내려받거나 끊김 방지를 보장하지 않습니다. 사용자가 변경한 배속이나 플레이어의 자체 속도 변경은 덮어쓰지 않습니다.

직접 재생 위치를 옮기면 대기 중인 입장 시 따라잡기는 취소됩니다. 되감기한 뒤에는 확장의 자동 배속을 멈추며, **즉시 따라잡기**를 누르거나 다른 방송에 입장하면 다시 사용할 수 있습니다.

- **지연:** 플레이어가 측정한 값의 평균으로, PC 시계 오차에 영향을 받습니다. 측정할 수 없으면 `—`로 표시합니다.
- **버퍼:** 현재 위치부터 끊김 없이 받아 둔 영상의 남은 시간입니다.
- **끝점까지:** 마지막 탐색 가능 위치까지의 거리이며, 실제 방송 지연과는 다릅니다.
- **연결 방식:** 실제 선택된 트랙 기준입니다. P2P 트랙이면 함께 표시하며, 확인할 수 없으면 확인 중으로 표시합니다.

문제를 확인하려면 팝업 하단의 **진단 로그 → JSON 저장**을 사용하세요.
