# 치지직지직

치지직 라이브의 재생 지연을 줄이고, 좁은 창에서 채팅을 영상 아래에 배치하며, Firefox에서 치지직 클립 편집기를 열 수 있게 하는 확장 프로그램입니다.

## 설치

Firefox 128 이상에서 설치할 수 있습니다. [Firefox 부가 기능에서 치지직지직 설치](https://addons.mozilla.org/ko/firefox/addon/chzzk-catch-up/)

팝업에 **치지직 접근 허용** 버튼이 표시되면 눌러 권한을 부여하고, 이미 열려 있던 치지직 탭을 새로고침하세요. 이 권한은 따라잡기, 클립 편집기, 채팅창 하단 배치에 공통으로 사용합니다. 배포 버전 0.4.1에서는 이 버튼이 **클립 편집기** 항목에 있습니다.

## 사용 방법

팝업에서 **따라잡기**, **클립 편집기**, **채팅창 하단 배치**를 각각 켜고 끌 수 있습니다. 스위치와 목록은 변경 즉시 저장되며, 숫자 입력은 Enter를 누르거나 입력칸에서 벗어나면 저장됩니다. 저장한 설정은 치지직 탭에 공통 적용됩니다.

### 라이브 따라잡기

- **입장 시 따라잡기**를 켜면 방송 재생이 안정된 뒤 버퍼를 일부 남기고 한 번 앞으로 이동합니다.
- **즉시 따라잡기**를 누르면 현재 위치에서 끊김 없이 이어지는 버퍼의 끝 가까이 이동합니다.
- **배속 따라잡기**를 켜면 1배속으로 재생 중이고 버퍼가 충분할 때 재생 속도를 높입니다. 실행 중인 배속은 플레이어에 표시됩니다.
- **연결 방식**은 **자동**(LL-HLS 우선), **HLS**, **LL-HLS** 중에서 선택합니다. 해당 연결 방식을 제공하는 방송에서 전환할 수 있습니다.

**자동 최적화**는 방송 중 영상이 들어오는 간격과 분량을 학습해 **남길 버퍼**와 **시작 버퍼**를 정합니다. 배속은 예측한 필요 버퍼보다 0.5초 이상 여유가 있을 때 시작하며, **최대 배속** 안에서 여유에 맞춰 재생 속도를 조절합니다. 학습 중이거나 영상 공급이 불안정하면 따라잡기를 기다립니다. 배속을 꺼도 입장 시 따라잡기와 즉시 따라잡기에 자동 최적화가 적용됩니다.

**끊김 방지 안전 수준**은 상(안정성 우선), 중(균형, 기본값), 하(짧은 지연 우선) 중에서 선택할 수 있습니다. 안전 수준을 바꾸거나 **버퍼 학습 초기화**를 누르면 현재 방송의 버퍼 보충 주기를 다시 학습합니다.

자동 최적화를 끄면 **시작 버퍼**(2~30초, 기본 3초), **남길 버퍼**(0.2~3초, 기본 0.6초), **배속**(1.1·1.2·1.5·2배, 기본 1.5배)을 직접 설정할 수 있습니다. 시작 버퍼는 남길 버퍼보다 최소 0.5초 커야 합니다. 배속 종료 기준에는 최소 0.6초가 적용됩니다.

### 라이브 재생 상태

| 팝업 표시 | 의미 |
| --- | --- |
| **지연 · 5초 평균** | 영상이 서버에 들어온 시점부터 현재 재생까지의 추정 지연을 최근 5초간 평균한 값 |
| **끝점까지** | 현재 재생 위치에서 마지막으로 탐색할 수 있는 위치까지 남은 시간 |
| **버퍼** | 현재 재생 위치부터 이미 받아 둔 연속 영상의 끝까지 남은 시간 |
| **현재 연결** | 플레이어에서 사용 중인 연결 방식. P2P 사용 시 함께 표시 |

일시정지 중에는 지연, 끝점까지, 버퍼의 마지막 표시값을 유지합니다. 지연은 치지직 HEAD 응답의 `Date`와 영상의 `ingest-utc`를 바탕으로 추정하며, PC 시계 대신 단조 경과 시간을 사용합니다. 재생 중 서버 시각을 약 30초마다 동기화합니다. 첫 동기화 전, 영상 시간 정보가 없을 때, 서버 시각을 90초 넘게 갱신하지 못했을 때는 지연을 `—`로 표시합니다.

### 채팅창 하단 배치

이 기능을 켜면 페이지 표시 영역이 설정한 너비(기본 1,000px) 이하일 때 라이브와 채팅이 있는 다시보기에서 채팅창이 영상 아래로 이동합니다. 세로 공간이 부족하면 아래로 스크롤해 채팅을 볼 수 있습니다. 기본값은 꺼짐입니다.

### 클립 편집기

방송의 가위 버튼을 눌러 클립 편집기를 엽니다. 소리가 들리지 않으면 음소거를 해제하고 볼륨을 올린 뒤 다시 재생하세요. 클립 생성에는 치지직의 로그인, 채널별 허용 여부, 생성 제한이 적용됩니다. Firefox에서 확인한 범위는 편집기를 여는 단계까지입니다.

팝업에서 **클립 편집 중 생방송 음소거 방지**를 켜면 클립 편집기를 열어도 시청하던 방송 소리를 계속 들을 수 있습니다. 특수효과를 켜면 편집기가 열린 동안 생방송에 고음 줄이기, 무전기 음색, 볼륨 20% 감소가 함께 적용됩니다. 오른쪽 패닝은 별도로 켤 수 있습니다. 세 옵션의 기본값은 꺼짐입니다.

## 자동 버퍼 제어 기준

| 안전 수준 | 초기 안전 여유 | 끊김 후 최소 증가량 | 안전 여유 상한 | 관측 최대 위험 반영 비율 |
| --- | --- | --- | --- | --- |
| 하 | 0.4초 | 0.3초 | 2초 | 25% |
| 중 (기본) | 0.6초 | 0.5초 | 3초 | 60% |
| 상 | 1.0초 | 0.8초 | 5초 | 100% |

필요 버퍼는 예측한 버퍼 소모량에 안전 여유를 더해 계산합니다. 끊김이 감지되면 표의 최소 증가량과 기존 여유의 35% 중 큰 값만큼 여유를 상한까지 늘립니다. 공급이 30초 이상 안정되면 안전 여유를 초당 0.005초씩 초기값까지 줄입니다.

최근 2분간의 기록을 최대 480개 보관합니다. 최근 변화는 20초간의 기록으로 평가하되, 기록이 6개보다 적으면 이전 기록도 포함합니다. 연속된 영상 유입 3회의 간격과 분량을 바탕으로 각 도착 직전의 버퍼 부족량을 계산합니다. 예측값의 80번째 백분위수와 최댓값 사이의 차이는 표의 비율만큼 반영합니다. 이미 기다린 시간 안에 영상이 도착한 사례는 다음 도착 예측에서 제외하며, 250ms 관측 간격에 따른 오차 여유를 더합니다.

새 유입 간격을 최소 6개 학습한 뒤 따라잡기를 시작합니다. 영상이 예상보다 늦게 들어오거나 최근 공급량이 정상 재생 소비량의 90% 미만으로 떨어지면 배속을 해제합니다.

입장 시 따라잡기와 즉시 따라잡기는 필요한 버퍼가 3초를 넘으면 위치 이동을 보류합니다. 입장 이동을 기다리는 중 배속이 먼저 시작되면 해당 방송의 입장 이동을 건너뜁니다. 배속은 더 큰 기존 버퍼를 사용할 수 있으며, 필요한 버퍼에 시작 여유 0.5초를 더한 값이 30초를 넘으면 대기합니다.

## 개발

소스에서 테스트하려면 Firefox의 `about:debugging#/runtime/this-firefox`에서 **임시 부가 기능 로드**를 누르고 `manifest.json`을 선택하세요. 임시 설치는 Firefox를 종료하면 해제됩니다. 반복해서 재로드한 뒤 팝업이 보이지 않으면 Firefox를 완전히 종료하고 다시 실행하세요.

Node.js 20 이상에서 테스트와 검사를 실행할 수 있습니다.

```sh
npm ci
npm test
npm run check
```

Windows에서 `npm run package`를 실행하면 서명 제출용 ZIP이 `dist/`에 생성됩니다. 서명된 XPI 파일을 직접 설치하려면 `about:addons`의 톱니바퀴 메뉴에서 **파일에서 부가 기능 설치**를 선택하세요.
