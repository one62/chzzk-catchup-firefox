# 치지직지직

치지직 라이브의 지연을 줄이고 Firefox에서 클립 편집기를 사용할 수 있게 하는 확장입니다.

## 주요 기능

- **연결 방식:** 자동(LL-HLS 우선), HLS, LL-HLS 중 선택합니다.
- **입장 시 따라잡기:** 재생이 준비되면 설정한 버퍼만 남기도록 한 번 앞으로 이동합니다.
- **즉시 따라잡기:** 버튼을 눌러 받아 둔 영상의 끝 가까이 이동합니다.
- **자동 배속:** 버퍼가 쌓이면 따라잡고 실행 중인 배속을 표시합니다. 자동 최적화 중에는 선택한 배속을 상한으로 삼아 여유에 맞춰 속도를 조절합니다.
- **자동 최적화:** 유입 간격과 영상 분량을 함께 학습해 여러 유입 구간 동안 필요한 여유를 예측합니다. 끊김 방지 안전 수준을 상·중·하로 선택할 수 있습니다.
- **재생 상태:** 서버 응답 시각으로 계산한 최근 5초 평균 지연·현재 버퍼·연결 방식을 표시하고 일시정지 중에는 표시를 멈춥니다.
- **클립 편집기:** Firefox에서 치지직 클립 편집기를 열 수 있도록 호환 처리를 적용합니다.

## 설치

Firefox 128 이상이 필요합니다.

- **임시 설치:** `about:debugging#/runtime/this-firefox` → **임시 부가 기능 로드**에서 `manifest.json`을 선택합니다.
- **영구 설치:** Mozilla 서명을 받은 XPI를 `about:addons` → 톱니바퀴 → **파일에서 부가 기능 설치**로 설치합니다.

임시 설치는 Firefox를 종료하면 해제되며, `dist`의 ZIP은 서명 제출용 패키지입니다.
설치·업데이트 후 치지직 사이트 접근을 허용하고 열려 있던 방송 탭을 새로고침하세요.

## 사용

- 팝업의 **따라잡기**에서 연결 방식·남길 버퍼·입장 시 동작·자동 배속·버퍼 자동 최적화를 설정합니다.
- 스위치와 목록은 변경 즉시 저장됩니다. 숫자 설정은 Enter를 누르거나 입력칸에서 벗어나면 저장됩니다.
- **자동 최적화**를 켜면 시작 버퍼와 남길 버퍼를 자동으로 정합니다. 배속은 예측 필요 버퍼보다 0.5초 이상 여유가 있을 때 시작하며, 학습 중이거나 보충 간격이 불안정하면 기다립니다.
- 자동 최적화는 배속을 꺼도 입장·즉시 따라잡기에 적용되며, 자동 최적화를 끄면 기존 수동 버퍼값을 다시 사용합니다.
- **끊김 방지 안전 수준:** 상은 안정성, 하는 짧은 지연을 우선하며 기본값은 중입니다. 변경하면 실행 중인 자동 배속을 해제하고 다시 학습합니다.
- 클립은 **클립 편집기 → 치지직 접근 허용** 후 방송을 새로고침하고 방송의 가위 버튼으로 엽니다.
- 편집기에서 소리가 없으면 음소거를 해제하고 볼륨을 올린 뒤 다시 재생합니다.

설정은 모든 방송 탭에 공통 적용되며, 지연·버퍼 조회와 즉시 따라잡기는 라이브에서 사용합니다.
지연은 치지직 HEAD 응답의 `Date`와 영상의 `ingest-utc`를 사용하며, PC 시계 대신 단조 경과 시간으로 갱신합니다.
서버 시각은 재생 중 약 30초마다 동기화하며, 초 단위 응답 시각과 왕복 시간에 따른 오차가 있는 추정값입니다.
동기화 전·영상 시간 정보 없음·서버 시각을 90초 넘게 갱신하지 못한 경우에는 지연을 `—`로 표시합니다.
클립 생성에는 치지직의 로그인·채널별 허용·생성 제한이 적용되며, 생성 완료까지는 아직 확인하지 않았습니다.
확장을 반복 재로드한 뒤 팝업이 보이지 않으면 Firefox를 완전히 종료하고 다시 실행하세요.

## 자동 버퍼 제어 기준

| 안전 수준 | 초기 안전 여유 | 끊김 후 최소 증가량 | 추가 안전 여유의 상한 | 관측 최대 위험 반영 |
| --- | --- | --- | --- | --- |
| 하 | 0.4초 | 0.3초 | 2초 | 작게 |
| 중 (기본) | 0.6초 | 0.5초 | 3초 | 중간 |
| 상 | 1.0초 | 0.8초 | 5초 | 전부 |

초기 안전 여유는 예측된 버퍼 소모량에 더하는 값이며, 전체 목표 버퍼의 고정값이 아닙니다. 학습 전에는 모든 수준에서 따라잡기를 보류합니다. 끊김 후에는 최소 증가량과 기존 여유의 35% 중 큰 만큼 늘립니다. 여유의 상한도 전체 필요 버퍼를 잘라 내는 한도가 아닙니다.

최대 480회의 기록을 2분 동안 보관하고 최근 20초(최소 6회)의 변화도 함께 반영합니다. 연속된 유입 간격·영상 분량 3쌍을 재생해 도착 직전의 버퍼 부족량을 예측합니다. 후보 부족량의 상위 20% 경계값에서 최댓값까지의 차이를 하 25%, 중 60%, 상 100% 반영합니다. 이미 기다린 시간보다 짧은 도착 사례는 다음 도착 예측에서 제외합니다. 관측은 250ms 간격이므로 그 오차 여유도 포함합니다.

최소 6개의 새 유입 간격을 학습해야 따라잡기를 허용합니다. 알려진 유입 간격을 넘어 기다리거나 최근 공급량이 정상 재생 소비량의 90% 미만이면 자동 배속을 즉시 해제합니다. 충분히 안정된 상태가 30초 이어진 뒤에만 추가 안전 여유를 초당 0.005초씩 줄입니다. 최대 관측 범위를 벗어나는 네트워크 장애까지 무중단을 보장하지는 않습니다.

즉시·입장 따라잡기는 현재 재생 위치를 포함하는 연속 버퍼 안에서만 이동합니다. 필요한 여유가 이동 한도인 3초보다 크면 이동을 보류합니다. 자동 배속은 더 큰 기존 버퍼를 사용할 수 있지만, 필요한 여유와 시작 간격이 시작 버퍼 설정 한도인 30초를 넘으면 보류합니다. 사용자가 직접 선택한 재생 속도는 변경하지 않으며, 해당 속도로 여러 유입 구간을 재생할 여유를 계산합니다.
