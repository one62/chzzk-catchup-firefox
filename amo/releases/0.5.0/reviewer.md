Version 0.5.0 adds optional controls to keep the live broadcast audible while the CHZZK clip editor is open and to apply an audio effect or right-channel panning. All three options are off by default. This release also moves the CHZZK site access control to the top of the popup and improves catch-up, settings recovery, and chat layout.

To test, grant CHZZK site access, open a live broadcast, and enable the keep-live-audio option in the extension popup. Open the clip editor with the broadcast’s scissors button. Verify that live audio remains audible, test the effect and panning independently, and close the editor to verify that the original audio state is restored.

The add-on ID, permissions, host access, and data collection declaration are unchanged. All 251 automated tests and repository checks passed. Live Firefox verification of the clip editor audio behavior is pending.
